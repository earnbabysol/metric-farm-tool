# Metric USDC/USDT 刷量工具

在 Metric 的 USDC/USDT 池子里来回兑换，赚交易积分。**不需要私钥、不托管资金，全部在你自己钱包里由你确认。**

## 怎么用（3 步）

### 1. 打开网页

**https://earnbabysol.github.io/metric-farm-tool/**

### 2. 连接钱包

点右上角「连接钱包」→ MetaMask 弹窗 → 确认。

> 需要在 **BNB Chain（BSC）**，钱包里要有 USDT 和 USDC。
> 如果提示网络不对，页面会请求切换，点「切换网络」。

### 3. 按顺序点

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① | **授权 USDC + USDT** | 第一次用要点，两笔确认，之后永久有效 |
| ② | 选池子 | 见下面「选哪个池子」 |
| ③ | 填金额和次数 | 小白建议先 $500 / 10 次 |
| ④ | 点「开始」| 每笔都要你在钱包确认 |

## 选哪个池子

| 池子 | 适合谁 | 成本 |
|---|---|---|
| **黄色池**（默认）| 所有人（别人的池子，深度 $130 万）| 约 **$7.4 / 每 $100 万** |
| **我的池** | 有自己 USDC/USDT 池子的人 | 约 **$6.1 / 每 $100 万**，但单笔 ≤ $2,500 |

**小白直接用默认的黄色池就行。**

## 参数怎么填

| 参数 | 建议 | 说明 |
|---|---|---|
| 单笔金额 | **$4,000** | 越大越省 gas |
| 模式 | **批量 50 次/确认** | 一笔交易打包 50 个来回 |
| 总次数 | **50** | 1 次 = 一个方向 |
| 间隔 | **3 秒** | |

这样一笔交易刷 **$200,000 成交额**，成本约 **$1.48**。

## 常见问题

**Q：会亏钱吗？**
A：会亏一点，就是手续费（价差）和 gas。**没有锁仓、没有质押、钱一直在你钱包里**，随时可以停。

**Q：积分值钱吗？**
A：不知道。Metric 的积分规则没公开，也没有承诺发币。**只刷你愿意承担风险的钱。**

**Q：为什么每笔都要确认？**
A：批量模式下，**一次确认会执行 50 次来回**，不是 50 次确认。看到「批量 50」就是一次确认。

**Q：失败了会怎样？**
A：交易 revert，只损失 gas（约 $0.3），资金不动。

**Q：怎么停？**
A：点「停止」，当前这笔完成后就停。

## 技术细节（给好奇的人）

- 路由：Metric Router `0x02201e6f13c41506c7bb635d7543f98826229ab7`
- 黄色池：`0xb3aDeb4a72948f68CcdC8C958a0bE4BCEa3C0677`（TVL 约 $130 万）
- 你的池：`0x6c820C6D15A0b8381D901613bFd76C9De091092D`（TVL 约 $10k，单笔上限 $2,500）
- 原理：`exactInputSingle` × N 打包进 `multicall`，每个来回 = 买入 + 卖出
- 页面只调用 MetaMask 的 `eth_requestAccounts` / `eth_sendTransaction`，不接触私钥
